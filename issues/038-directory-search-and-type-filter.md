# Issue 038: 現在のディレクトリ内の名前検索と種類フィルタ

## 目的

現在のディレクトリにある項目を、名前の部分一致とファイル種類で絞り込めるようにする。絞り込み時にファイルシステムへのアクセスやSSH通信を追加しない。

## 対象範囲

- 一覧に、ラベル付きの名前検索欄と種類の選択欄を追加する。
- 名前は大文字・小文字を区別せず、入力文字列の部分一致で判定する。日本語や記号も扱う。
- 種類は複数選択でき、選んだ種類のいずれかに一致する項目を表示する（種類同士はOR）。名前検索を併用した場合は、名前条件にも一致する項目を表示する（名前と種類集合はAND）。
- 種類が未選択なら全種類を対象にする。検索欄を空にし、種類の選択を解除すると全件表示へ戻る。
- 既存の分類（ディレクトリ、Markdown、画像、HTML、CSV、TSV、JSON Lines、音声、動画、テキスト、その他のファイル）を使う。
- ディレクトリにも両方の条件を適用し、種類としてディレクトリを選べるようにする。
- 表示件数と総件数、条件を解除する操作を用意する。「一致する項目がない」と「空のディレクトリ」を区別して表示する。
- 絞り込みで隠れた項目は選択を解除する。全選択とZIPダウンロードは表示中の項目だけを対象とし、全選択欄の選択済み・一部選択の状態を更新する。
- 読み取り専用と書き込み有効の両方で動作させる。ファイルリンク、親への移動、ダウンロード、アップロードの既存動作を維持する。
- ディレクトリ一覧の見た目を整える。検索欄・種類選択・解除ボタンの高さと配置、見出しとパスの強弱、表の余白、ボタン、選択状態、明暗テーマを統一する。
- 配色は従来のブラウザ標準の明暗配色を維持する。独自の緑系配色は使わず、背景・文字・リンク・ボタンの色はシステムカラーに従う。
- 再帰検索、曖昧検索、内容検索、新しい依存関係、検索条件の永続化は対象外とする。
