# Issue 040: Go 1.27への固定

## Goal

開発・CI・release・静的解析で使うGoを1.27.2に統一する。

## Scope

- `mise.toml`でGo 1.27.2を固定し、analysis環境のGo指定を削除して共通設定を継承する。
- deadcodeをv0.52.0、staticcheckをv0.8.2に更新する。既存の解析ツールは旧GoでのbuildやGo 1.27.2のexport data形式により失敗したため、対応版を新しいGoで導入する。
- CIの同一Goバージョンでの重複検証をまとめ、既存の検証項目を維持する。
- READMEとPLANへ現在のツール構成を記録する。
- `go.mod`の最低対応バージョンは変更しない。実行するtoolchainの固定はmiseで行う。
- tracked helper artifactは再生成しない。

## Relevant files

- `mise.toml`, `mise.analysis.toml`
- `.github/workflows/ci.yml`, `.github/workflows/release.yml`
- `README.md`, `PLAN.md`, `go.mod`

## Acceptance criteria

- 通常環境・analysis環境の両方でGo 1.27.2を選択する。
- test / race / vet / build、server OS selection、deadcode / staticcheckの検証を維持する。
- Windowsとreleaseも共通のGo設定を使用する。
- 既存のユーザー変更を変更・commitしない。

## Verification

- PASS: mise installと通常環境・analysis環境の`go version`（1.27.2）。
- PASS: `mise exec -- make check`（test / race / vet / build）。
- PASS: server_linux / server_darwin / server_windowsのtestと各SERVER_OS指定でのbuild。
- PASS: analysis環境のdeadcode v0.52.0 / staticcheck v0.8.2。
- PASS: 6 platformのrelease archive生成、SHA256SUMS照合、各binaryのbuild情報がGo 1.27.2であることを確認。
- PASS: actionlint v1.7.12（shellcheck無効）、`git diff --check`、go.mod / Makefile / helper artifactの差分なし。
- 未実施: Windows runner上の実行とGitHub Actions自体の実行。更新済みworkflowで確認する。

## Current state

- 完了。Goの指定は`mise.toml`の1.27.2へ集約し、通常環境・analysis環境・CI・releaseで共有する。
- 解析ツールをGo 1.27.2で導入して検証した。Staticcheck v0.8.1のexport data読込エラーは、[Go 1.27.2対応版のv0.8.2](https://github.com/dominikh/go-tools/releases/tag/2026.2.2)への更新で解消した。
